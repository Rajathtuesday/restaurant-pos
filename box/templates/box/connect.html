Every device must be on the restaurant's Wi-Fi (or cable). The box needs no internet.

Android phone or tablet

  1. Install the Rasova app (version 1.3.0 or newer) from this box: download it here on the phone. Android may ask to allow installs from Chrome: allow it once.
  2. Open it and tap Scan QR code, then scan this code.
  3. Sign in. The app opens straight to this box from then on.

If the phone says "Wi-Fi has no internet access", tap Stay connected: the box is on the Wi-Fi, not the internet.

No app? Scan the code with the phone's camera: Rasova opens in Chrome.

iPhone or iPad

  1. Open Safari (not Chrome) at {{ address }}, or scan the code with the camera.
  2. Tap the Share button (the square with an arrow).
  3. Tap Add to Home Screen, then Add.

Rasova gets its own icon and opens full screen, without Safari's address bar.

Windows PC at the counter

Download the shortcut
  1. Download it on the counter PC and move it to the desktop.
  2. Double-click it. If Windows asks whether to run it, choose Run.
  3. Rasova opens in its own window, like an app.

To open it whenever the PC starts: press Windows+R, type shell:startup, press Enter and copy the shortcut into that folder.

A Mac: open the address in Safari, then File, Add to Dock.

So nobody types an address again

  • Give the box a fixed address on the router (a DHCP reservation), and the printers too. If the box's address ever changes, open this page at the new one and pair the phones again.
  • A sign-in lasts a day on each device. The box and the router on a UPS keep everyone connected through a power cut.
