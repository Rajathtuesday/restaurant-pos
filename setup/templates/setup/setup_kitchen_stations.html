Printer quick-start:
1. Connect printer to your Wi-Fi router (or use a static IP).
2. Find its IP from the printer's self-test page (hold Feed button on power-up).
3. Paste the IP here, pick the correct paper width, hit Save.
4. Click Test Print — if text fits the paper, you're done.
